# Milestone 4: Ticket Creation & Management

**Issue:** Ticket Creation, Editing, and Basic Management

**Checklist:**
- [ ] Create new ticket form (Customers only)
- [ ] Ticket title, description, category selection
- [ ] Ticket priority selection (Low, Medium, High, Urgent)
- [ ] View ticket details page
- [ ] Edit ticket (Creator or Admin only)
- [ ] Delete ticket (Admin only)
- [ ] List tickets with pagination

**Description:**
Implement the core ticket management system allowing customers to create tickets, assign categories and priorities, and view/edit their tickets. Admins have full management capabilities including deletion and bulk operations.

**Expected Result:**
- Customers can create tickets with required fields
- Tickets have categories and priority levels
- Proper access controls on edit/delete operations
- Ticket list supports searching, filtering, and pagination
- Ticket detail page shows full information including comments
