# Milestone 5: Ticket Assignment & Workflow

**Issue:** Ticket Assignment, Status Management, and Workflow

**Checklist:**
- [ ] Assign tickets to support agents
- [ ] Ticket status management (Open, In Progress, Resolved, Closed)
- [ ] Status transition workflow
- [ ] Agent workload view
- [ ] Unassign ticket functionality
- [ ] Bulk operations (Admin only)

**Description:**
Implement ticket assignment system where admins can assign tickets to specific support agents. Define status lifecycle for tickets and ensure valid transitions. Provide agents with workload management and unassign capabilities.

**Expected Result:**
- Admins can assign tickets to specific agents
- Tickets progress through valid status states (Open → In Progress → Resolved → Closed)
- Agents see only their assigned tickets
- Workload distribution view for admins
- Valid status transitions only (no invalid jumps)
- Admin can bulk-assign or bulk-update ticket status
