# Milestone 6: Comments & Notifications

**Issue:** Ticket Communication and Notification System

**Checklist:**
- [ ] Add comments to tickets
- [ ] Distinguish internal comments (Admin/Agent) vs public comments
- [ ] Comment author role-based display
- [ ] Email notifications on ticket updates
- [ ] Real-time update mechanism (WebSockets or polling)
- [ ] User notification preferences

**Description:**
Enable communication within tickets through comments and implement notification system to alert users of relevant changes. Support both public comments (visible to ticket customer) and internal notes (visible to admins/agents only).

**Expected Result:**
- Users can add comments to their tickets
- Admins/agents can add internal notes not visible to customers
- Comment display respects role permissions
- Notifications sent for status changes and new comments
- Real-time updates without page refresh
- Users can opt-out of specific notification types
